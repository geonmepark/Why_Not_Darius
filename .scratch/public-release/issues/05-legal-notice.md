# 푸터 법적 고지

Type: task
Status: resolved

## Question

공개 배포하면 Riot 서드파티 조건이 실제로 적용된다. `MarketingFooter.tsx` 에
두 줄을 넣는다.

- Riot Games 의 승인을 받지 않았고 Riot Games 가 관여하지 않는다는 취지의 고지
- 데이터 수집 없음 — 서버가 없고 전부 로컬 파일이라 사실 그대로다

수집하는 데이터가 없으므로 별도 개인정보 처리방침 페이지는 만들지 않는다.

## Answer

`MarketingFooter.tsx` 를 두 영역으로 나눴다. 위쪽은 기존 브랜드/링크 행, 아래쪽에
구분선을 두고 고지 두 건을 넣었다.

- **데이터 수집 없음** — ShieldCheck 아이콘과 함께 강조. "계정도 서버도 없으며,
  설정한 카운터픽은 사용자 PC 에만 파일로 저장됩니다." 실제 구조가 그러하므로
  사실 그대로의 진술이다.
- **Riot 고지** — 기존의 짧은 상표 문구를 Riot 서드파티 조건이 요구하는 형태로
  확장했다. 승인받지 않았고 Riot 의 견해를 반영하지 않는다는 점을 명시.

개인정보 처리방침 페이지는 만들지 않았다. 수집하는 데이터가 없어 링크할 내용이 없다.
