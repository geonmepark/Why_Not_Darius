# 미서명 설치 안내 섹션

Type: grilling
Status: resolved

## Question

서명이 없어 사용자는 설치까지 두 개의 경고를 넘어야 한다. 안내가 없으면
SmartScreen 파란 화면에서 대부분 이탈한다(기본 버튼이 "실행 안 함").

마케팅 사이트에 안내 섹션을 만든다. 다뤄야 할 단계:

1. 브라우저의 "일반적으로 다운로드되지 않는 파일" → 유지
2. SmartScreen "Windows가 PC를 보호했습니다" → 추가 정보 → 실행
3. 왜 뜨는지 — 서명 인증서가 없어 뜨는 정상 경고라는 설명

배치 위치(다운로드 페이지 전용 vs `DownloadCTA` 바로 아래)와 톤을 정한다.
스크린샷은 실제 릴리스 후 캡처해 넣는다.

## Answer

`InstallGuide.tsx` 를 만들어 `/download` 페이지의 다운로드 섹션 바로 아래 배치했다.

**배치**: 다운로드 페이지 전용. 랜딩 히어로에 두면 아직 받지도 않은 사람에게
경고부터 보여주는 셈이라 전환을 깎는다. 받기 직전/직후에 보이는 자리가 맞다.
다운로드 섹션의 각주도 FAQ 대신 이 섹션(`#install-guide`)을 가리키게 바꿨다.

**톤**: 사과하지 않고 사실만 말한다. "바이러스가 검출돼서가 아니라, 서명이 없는
새 파일이면 무조건 뜨는 화면"이라고 먼저 안심시키고, 왜 서명을 안 했는지(연 수십만 원)
를 밝힌다. 숨기는 것처럼 보이면 오히려 의심을 산다.

**구조**: 3단계. 각 단계마다 "화면에 이렇게 뜨면" → 실제 문구 → 누를 버튼.
2단계(SmartScreen)만 primary 색과 "여기서 대부분 막힙니다" 배지로 강조했다.
기본 버튼이 "실행 안 함" 이라 실제 이탈이 거기서 일어나기 때문이다.

FAQ 도 실제 동작에 맞게 고쳤다. "자동 업데이트 향후 지원 예정" → 앱 내 알림
배너로 바뀐 사실을 반영하고, 보안 경고 항목은 이 가이드를 가리키게 했다.

**남은 것**: 실제 스크린샷. 릴리즈된 exe 로 캡처해야 문구가 정확하다. 지도의
Not yet specified 에 남겨둔다.
